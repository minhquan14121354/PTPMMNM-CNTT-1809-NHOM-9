# Quy trình Đóng góp Mã nguồn
1. Fork kho chứa về tài khoản cá nhân.
2. Tạo nhánh tính năng mới (`git checkout -b feature/AmazingFeature`).
3. Cam kết thay đổi (`git commit -m 'Add some AmazingFeature'`).
4. Đẩy lên nhánh (`git push origin feature/AmazingFeature`).
5. Mở Pull Request để trưởng nhóm duyệt mã nguồn.
